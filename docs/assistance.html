Questions fréquentes

Le micro ne marche pas

Vérifie que Prout Box a le droit d'utiliser le micro : Réglages › Prout Box › Micro. Si tu as refusé la première fois, c'est là que ça se règle. Mets aussi l'app à jour : la version 1.1.1 corrige un bug qui bloquait l'enregistrement.

Ça ne prout pas quand je retourne le téléphone

Touche d'abord la boîte une fois : iOS demande alors l'accès au capteur de mouvement. Ensuite, retourne franchement le téléphone face vers le bas.

Pas de son en mode silencieux

L'app force le son même en mode silencieux. Si rien ne sort, monte le volume avec les boutons sur le côté et vérifie qu'aucun casque Bluetooth n'est connecté.

Comment retirer un prout que j'ai publié ?

TOP PROUTS › onglet MOI ou PAYS › touche ton prout › SUPPRIMER (deux fois pour confirmer). Dans un groupe : GALERIE › ton prout › RETIRER. Si tu as changé de téléphone, écris-nous avec tes initiales, le pays et la date, on le retire.

Je veux signaler un prout

Touche le prout, puis SIGNALER (deux fois). Dans le classement public, le prout est masqué pour tout le monde à partir de trois signalements ; dans un groupe, il disparaît immédiatement. Nous examinons les signalements régulièrement.

Ma ville affichée est fausse ou je ne veux pas la montrer

La ville est approximative et facultative. Avant de publier, touche « 📍 VILLE · TOUCHE POUR RETIRER ». Tu peux aussi refuser la permission de localisation : le pays suffit.

Supprimer toutes mes données

Désinstaller l'app efface tout ce qui est sur le téléphone. Pour les prouts publiés en ligne, retire-les depuis l'app ou écris-nous : nous les supprimons, fichiers compris.
